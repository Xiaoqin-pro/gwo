# I-GWO 基线实现更正（2026-10-16）

## 结论：之前的 `IGWO.m` 是**错误实现**，构成"稻草人基线"，已重写

外部评审对照原作者源码（MATLAB File Exchange 81253 / VG-TechCenter 镜像）指出四处差异，
已全部修正。**修正后 I-GWO 明显更强**，这会改变全部对比结论。

### 四处差异与修正

| # | 机制 | 旧（错误）实现 | 原作者实现 | 影响 |
|---|---|---|---|---|
| 1 | **个人历史最优保留** | 直接接受 X_GWO / X_DLH 中较好的新位置 | 只有新候选**严格优于该狼自己的历史最优**才替换 | 旧版会让狼漂移到更差的位置；这是最大的差异 |
| 2 | **DLH 逐维邻居** | 所有维度共用同一邻居 | `X_DLH(t,d)=X(t,d)+r_d*(X(n_d,d)-X(r(t),d))`，**每维独立抽邻居** | 改变 DLH 候选的概率分布 |
| 3 | **领导层来源** | 每评价一个候选就尝试更新 α/β/δ（候选可能最终未被接受） | 只在每代开始、从**保留种群** `Positions/Fit` 更新 | 改变后续搜索轨迹 |
| 4 | **越界处理** | 直接截断到边界 | 中点修正：`v<LB → (old+LB)/2`，`v>UB → (old+UB)/2` | 旋转/组合函数上影响性能 |
