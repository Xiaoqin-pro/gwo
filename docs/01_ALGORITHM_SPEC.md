# 算法规格 v2（当前冻结版本）— RASE-GWO

> 唯一事实来源。代码偏离本文件时必须先改本文件。
> v1 的"稀疏省预算"路线已被实验否定，v2 把主线改成**过采样 + 评价名额分配**。

## 0. 研究问题

> 真实目标函数评价昂贵、候选位置生成便宜时，GWO 应该把有限的名额给哪些候选狼？

**与已有 Q-learning-GWO 文献的分界**：他们改的是"狼怎么搜"（算子/参数/领导选择）；
我们改的是"哪些狼值得花一次真实评价"。搜索方程一行不改。

## 1. 一句话机制

```
每轮：M 只虚拟狼按标准 GWO 方程移动（不花评价）
      ↓
      几何筛选出 K 个候选（K 远小于 M）
      ↓
      只有这 K 个消耗真实评价
      ↓
      用"已验证位置"重排 α/β/δ
```

**核心解耦**：虚拟搜索状态 `Y` ≠ 已验证状态 `Xv`。只有被真实评价过的位置才能当领导狼，
所以未评价的移动永远不会污染领导层。

## 2. 记号

| 符号 | 含义 |
|---|---|
| `M` | 虚拟狼数量（过采样倍数 M/K） |
| `K` | 每轮真实评价名额（默认 = N_canonical = 50） |
| `Y ∈ R^{M×D}` | 虚拟位置（搜索状态） |
| `Xv ∈ R^{M×D}`, `fv` | 最近一次被真实评价确认的位置与适应度 |
| `Xα,Xβ,Xδ` | 由 `(Xv, fv)` 排序得到的前三（**只能来自已验证位置**） |
| `X_L` | 领导中心 `(Xα+Xβ+Xδ)/3` |

初始化：只评价前 `K` 只狼（消耗 K 次 FE）；其余 M−K 只 `fv=∞`，暂时不参与领导竞争。
**前 K 个初始点与所有对拍算法严格相同**（共享 50 点前缀池），所以初始 α/β/δ 完全一致。

## 3. 每轮的三个步骤

### (a) 移动（不消耗 FE）
```
a = 2 − 2·FE/budget
A1 = 2a·r1 − a,  C1 = 2·r2      （r1,r2 为 M×D 均匀随机矩阵，逐个狼逐维独立）
D_α = |C1⊙Xα − Y|,  Y1 = Xα − A1⊙D_α     （β、δ 同理）
Y ← clip((Y1+Y2+Y3)/3, lb, ub)
```
**注意**：随机系数必须逐维独立。已实测：把 A/C 退化成"每只狼一个标量"会让 GWO 与
本方法同时崩掉（F1 误差差一个数量级），所以这不是可省的实现细节。

### (b) 筛选（几何、无代理模型）
```
dc(i) = ‖Y_i − X_L‖          % 收敛潜力，越小越优先
dd(i) = ‖Y_i − centroid(Y)‖  % 多样性潜力，越大越优先（divCriterion='centroid'）
```
- 取 `dc` 最小的 `Kc` 只 → 收敛组 `Ecvg`
- 取 `dd` 最大的 `Kd` 只 → 多样性组 `Ediv`
- `Kc = round(share·K)`，`Kd = K − Kc`
- `E = unique(Ecvg ∪ Ediv)`，若不足 K 则按"收敛次优 / 多样性次优"交替补足到**恰好 K**
  （保证每轮 FE 数恒为 K，与等轮数基线严格对齐）

### (c) 评价与领导刷新
对 `i ∈ E`：`v = f(Y_i)`，`FE += 1`
- `verifiedMode='latest'`：`Xv_i ← Y_i`，`fv_i ← v`
- 之后用 `(Xv, fv)` 重新排序得到 α/β/δ

## 4. 协议（关键：两个协议都要报）

### 协议 A：等 FE、等轮数（**主结果**）
所有算法 `budget = 100000` 次真实评价、`D=50`。
- 标准 GWO：N=50，每轮评价 50 只 → 2000 轮。
- RASE-GWO：M=1000 只虚拟狼，每轮评价 K=50 只 → 同样 2000 轮、同样 100000 FE。
- **唯一差别**：RASE-GWO 花了 M/K=20 倍的位置更新算术（便宜的资源），
  换来从 1000 个候选里挑 50 个来评价。

### 协议 B：稀疏省预算（次要结果 / 诚实报告）
RASE-GWO 用 20000 FE 跑 2000 轮；基线用 100000 FE 跑 2000 轮。
**实测结论：对 GWO 不成立**（GWO 每轮 50 次评价的信息量太大，稀疏版在等轮数下明显更差）。
这条要写进论文，用来界定框架的适用范围，不能只报有利结果。

## 6. 已完成的负面/中性结果（必须保留，不得调参掩盖）

| 实验 | 结论 |
|---|---|
| 稀疏省预算（M=50,K=10，等轮数） | **劣于 GWO**，两条配额都输 → 协议 B 不成立 |
| 朴素缩种群（GWO-N10） | 明显更差（排名靠后） |
| 随机筛选替代几何筛选 | 明显更差（M=1000 时 6.17 vs 3.25 平均排名） |
| `randMode='wolf'`（标量系数） | 崩坏，不是可省的实现细节 |
| 漂移门控 `driftGate` | 无效果（阈值从不激活） |
| Q 学习（默认参数，动作 {5:5,7:3,9:1}） | **劣于固定 9:1**（5.50 vs 3.25 排名） |

## 7. 当前最优配置（截至 2026-10-16 的 12 函数 × 10 种子筛选）

- M=1000、K=50、share=0.9，平均排名 3.25（11 个算法的批次里），对 GWO 9 胜 3 负，
  中位误差比 0.737；GWO 同批排名 6.58。
- M=2000 略好（2.92）但 CPU 从 4.5s 涨到 8.3s。
- 固定 10:0（share=1.0）与 9:1 基本持平（3.17）。
- 运行时：RASE-GWO 4.5s vs GWO 1.0s（CEC2017 目标函数很便宜；论文必须按"评价昂贵"的前提解释，
  同时如实报告这个数字）。
