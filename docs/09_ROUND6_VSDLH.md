# 第六轮：真实成功方向引导 DLH（VS-DLH）预登记

> **本文件在 `vsdlh` 批次启动前写下。**

## 机制

I-GWO 的 DLH 候选目前只用**邻居的位置**：

    X_i^DLH = X_i + r_d (X_{n_d,d} - X_{r,d})

它没有利用"哪些真实验证过的移动确实改善了目标函数"。本机制把稀疏评价产生的
**可靠位移信息**回灌到候选生成里：

1. 记录：当真实评价的候选 `Y_i` 优于该狼已验证最优 `X_i^old` 时，存一条
   `S = Y_i - X_i^old` 到环形档案（容量 20），同时记录其出发点，便于优先借用
   **空间相近**的成功方向。
2. 修正：对约 25% 的狼，把方向叠加到 DLH 候选上
   `X_i^new = X_i^DLH + λ·r_i·S_j/(||S_j||+ε)`，其中 `r_i = ||X_i^GWO - X_i||`
   是该狼本轮的 GWO 步长尺度，λ=0.25。没有合适记录时直接退回原版 DLH。
3. 不增加任何真实评价；方向采样用独立随机流，不扰动搜索流。
