# 第十轮：30 种子确认几何筛选的独立价值

批次的预登记文件（`docs/11`）因命令失败未能事前入库，已在其中如实记录。
本轮是**按对话中约定的门槛做的正式检验**，统计空间在 30 种子下才成立。

## 结果（29 函数 × 30 种子，100k FE，配对 Wilcoxon + Holm）

| 算法 | 平均排名 |
|---|---:|
| **RASE-IGWO-K25（几何）** | **1.621** |
| RASE-IGWO-K25-r（随机） | 2.069 |
| IGWO（全评价） | 2.310 |

| 比较 | 函数胜负 | 中位误差比 | Holm 显著 | 最小 p |
|---|---:|---:|---:|---:|
| **几何 K25 vs 随机 K25** | **20/9** | **0.921** | **11 好 / 2 差** | **1.86e-09** |
| 随机 K25 vs 全评价 | 18/11 | 0.995 | 0 / 0 | 0.052 |
| 几何 K25 vs 全评价 | 20/9 | 0.929 | 11 / 3 | 1.86e-09 |

合并审计：290 组重叠运行逐位一致（相对差 0.000e+00）。

## 结论（本文的核心因果证据）

1. **几何筛选有独立且显著的贡献**：同 K=25 下对随机筛选 **20/9、比值 0.921、
   11 个函数显著更好、2 个显著更差**。10 种子时的"0 显著"确系门槛不可达所致。
2. **单独减少评价次数没有贡献**：随机 K25 对全评价 **18/11、比值 0.995、零显著**
   （最小 p = 0.052），即与全评价统计上不可分。
   → **"少评价"本身无效；有效的是"挑哪些来评价"。**
3. **优势依赖函数结构**（必须如实报告）：几何大幅占优 F1（比值 0.001）、F13（0.114）、
   F12（0.400）、F6（0.488）；而几何明显更差的是 F9（2.454）、F14（2.125）、F30（1.388）。
   这引出一个值得单独研究的问题：**什么结构下"优先验证领导共识附近的候选"有效，
   什么结构下它造成过度集中。**

## 措辞更正（评审指出的分母问题）

I-GWO 每代生成 **2N = 100** 个候选，K=25 评价其中 **25 个 → 25% 的候选**；
它相当于种群规模 N=50 的**一半**，**不是"一半候选"**。
此前文档中"每代只验证一半候选"的表述已按此更正，论文中两个分母必须统一。
